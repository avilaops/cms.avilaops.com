Biblioteca "docs" do estúdio da Ávila Ops.

Os componentes (barra lateral, sumário, navegação anterior/próxima, chamada,
cartão, abas e busca) foram reimplementados em HTML, CSS e JavaScript sem
empacotador. O código React, Next.js e MDX do Fumadocs não faz parte deste
repositório.

Os valores de cor neutros reproduzidos na folha de estilo do estúdio saem de
packages/radix-ui/css/lib/default-colors.css na revisão
76408e07e37cbe9708c194ad4f0ebd49a974a236 (branch dev, 2026-11-02) de
https://github.com/fuma-nama/fumadocs
